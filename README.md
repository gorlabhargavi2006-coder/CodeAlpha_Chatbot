# Basic Chatbot

A simple Python-based rule-driven chatbot developed as part of my CodeAlpha Python Programming Internship.

## 📌 Project Description

This project is a console-based chatbot that interacts with users using predefined rules and responses.

The chatbot can recognize common messages such as greetings, asking how it is doing, thanking, and exit commands.

## ✨ Features

- Responds to greetings such as `hello`, `hi`, and `hey`
- Responds to `how are you`
- Responds to `thanks` and `thank you`
- Supports exit commands such as `bye`, `goodbye`, `exit`, and `quit`
- Handles unknown messages
- Runs continuously until the user exits
